# 📊 Contador de Linguagens

Projeto de **Contador de Linguagens** desenvolvido utilizando apenas **HTML e CSS**, com foco em exibir tecnologias de forma visual, organizada e com estilo moderno.
A interface apresenta cartões com linguagens e números destacados, ideal para seções de habilidades ou estatísticas.


## 🚀 Tecnologias Utilizadas

* HTML5
* CSS3
* Flexbox
* Responsividade

---


## 🎯 Objetivo do Projeto

Este projeto foi desenvolvido para praticar:

* Estruturação com HTML
* Estilização com CSS
* Layout com Flexbox
* Criação de cards informativos
* Organização visual de dados
* Boas práticas de CSS
